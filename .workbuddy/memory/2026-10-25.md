## LAB1 网站改造：算法可视化剧场（2D + three.js 3D）

**目标**：把 LAB1 的表单式演示页改成「左动画 / 右源码 / 逐步高亮 / 自动循环 / 全屏」，
集成 lab_without_ai 的 lab1–lab4 源码，实验四做成云大呈贡校区 3D 地图。

**结构**（`LAB1/web/`）：
- `index.html` 四个实验屏；`css/app.css` 漫画风主题（米纸/墨线/网点）。
- `js/core.js`：`Player`（自动循环、单步、倍速、进度条、全屏）、`CodePanel`
  （fetch 源码 → 行号 DOM → 高亮滚动，`position:relative` 才能用 offsetTop）、
  `CanvasView`（DPR 自适应）、`mountLab`。
- `js/annotations.js`：按函数区间标注 `core / helper / data`，行号与真实源码一致。
- `js/lab1.js` 多项式链表 + 高斯消元；`lab2.js` 迷宫 DFS；`lab3.js` 二叉树 + 哈夫曼；
  `campus-data.js` 22 点 46 边 + 景物；`lab4-scene.js` 3D 场景；`lab4.js` Dijkstra/DFS 步骤。
- `web/src/lab1..lab4/` 从 lab_without_ai 原样拷贝；`web/vendor/three.min.js` r160。

**服务端** `webui.c`：首页分支改为 `web/` 静态托管（`MimeType/SafePath/SendFile/ServeStatic`，
16KB 分块、拒绝 `..`），`POST /api` 原样保留；`-Wall -Wextra` 零警告。

**关键教训**：
- 网格容器子项要 `min-height:0`，否则长源码把 `canvas-host` 撑到 5000+ px，画布看不到内容。
- 步骤里的 `file` 是源码路径，`CodePanel.show` 要同时接受 key 与 path（建 `byPath` 映射）。
- tab 切换 `dataset.lab` 是字符串，`registry.find(l => l.id === id)` 要先 `Number()`，否则不启动动画。
- 树布局用「叶子占格、父居中」比纯中序更像课本（`ABC##DE#G##F###` 的中序根会跑到最右）。
- 3D 水面 `ExtrudeGeometry` 旋转后顶面法线朝下，必须 `side: DoubleSide`，否则只看到湖底。
- 顶点浮标要悬在建筑上方（y≈48）并加光柱，否则被屋顶挡住，算法状态看不见。
- 标签用屏幕坐标做碰撞剔除，按 current/path > 地标 > 校门 > 普通 > 景物 排优先级。

**验证**（Puppeteer + 无头 Chrome + SwiftShader）：
步数 poly 84 / gauss 65 / maze 273 / tree 105 / huff 103 / dijkstra 86 / dfs 142；
循环、键盘、全屏、拖拽、地点信息卡、480px 窄屏均实测通过；控制台零报错。
