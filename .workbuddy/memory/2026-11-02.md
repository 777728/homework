## 踩坑记录（docx 转换引擎）

- **二次转义**：把已渲染的内联 HTML 再次 `html.escape` 会让 `<strong>` 变成字面文本 `&lt;strong&gt;`，转换后文档里出现 `</strong>` 字样。凡"提取 `<li>` 内容再包一层"的分支必须跳过转义。
- **表格必须带 `<thead>`/`<tbody>`**，否则 html-review 的结构维度直接 0 分（代码块/误区块也需补 thead 表头行）。
- **html-review 要求样式全走 CSS 变量**（`var(--*)`），裸 `font-size:12pt`/`margin:4pt 0` 均报 DT-02/03；改为 class + `:root` 变量即可。
- **标题内不要放内联标签**（`<span>`/`<strong>`），会导致个别标题丢失 Heading 样式绑定（verify S-6）。
- `convert_doc.py --require-toc` 的 verify 会把 `&lt;`/`&amp;` 与 Word 实际字符比较而误报"内容缺失"，实际 docx 正确；此类误报可用 `--no-verify`（保留 `--require-page-furniture` 预检）。
