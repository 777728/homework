## 项目重写：一元稀疏多项式计算器（数据结构 LAB1）

**补充（同日下午）**：按用户要求增加图形界面。原计划 GTK3，但 brew 被
沙箱拦截无法安装，改为零依赖方案：
- `webui.c`（约 420 行）：C 内置极小 HTTP 服务（只监听 127.0.0.1:8765，
  Win32/POSIX 双分支）+ URL 编解码 + 请求分发；
- `web/index.html`：仿 WinForms 表单页（两个选项卡：多项式计算 / 线性方程组），
  fetch POST /api，文本协议 `op=add&A=...&B=...`，错误以 `ERR:` 前缀返回；
- `LinearSolver.c` 重构：抽出 `MatFormat` / `MatSolutionText`（字符串版），
  控制台打印改为其包装，界面与控制台共用一套排版；
- 入口二选一：`app`（控制台）与 `app-web`（窗口界面），`./build.sh web` 或 `make web`。
- 已验证：编译零警告、17/17 自检、ASan 无报错、无头 Chrome 截图确认界面正常。
- 教训：HTTP 路由必须先剥掉 `?query` 再匹配路径；工具的后台进程要用
  run_in_background（裸 `&` 会被回收）。

**背景**：原工程用 C++ 风格（`float`、无头结点、`Term/Poly` 命名）实现，与实验要求的
「带头结点单链表 + 教材接口命名」不一致，且存在乘法只乘对角线、减法未取反、
求导产生 x^-1 等 bug。

**本次完成**：
- 全量重写为 5 模块 C11 工程：`Polynomial.c/h`（链表与多项式运算）、
  `LinearSolver.c/h`（高斯-约当消元、通解）、`ui.c/h`（控制台界面工具）、`main.c`（菜单与自检）。
- 存储结构改为带头结点单链表（`LinkList{head,tail,len}`），接口命名对齐教材：
  `MakeNode/InitList/DestroyList/CreatPolyn/PrintPolyn/AddPolyn/SubPolyn/MultiplyPolyn`。
- 新增字符串表达式解析 `CreatPolynFromString("3x^2-2x+1")`。
- 输出格式对齐题目要求：`9X^8+3X+7`，系数 ±1 省略、指数 1 省略、`%.10g`。
- 内置 17 条自检用例（主菜单 [4]），全部通过；ASan/UBSan 无告警；
  `leaks` 检测 0 泄漏。
- 补文档：`README.md`（使用说明）、`实验报告.md`（CDIO 四阶段 + 算法分析 + 思考题）。

**性能实测**（clang -O2，随机指数最坏情况）：
100×100 乘法 10k 次 → 17 ms；300×300 → 90k 次、34139 项、155 ms。

**约定**：编译必须 `-std=c11 -Wall -Wextra` 零警告；数值一律 `double`，
零判定用 `POLY_EPS = 1e-12`；所有 `malloc` 结点在退出前释放。

## 实验四 / 五 / 六 与四区域页面整合（同日晚些时候）

用户提供了《2025 秋课程实验方案.docx》和《实验指导书 2015 修订版.pdf》，
要求实现实验四（数组·迷宫）、实验五（树）、实验六（图），并与 Lab1 整合到
同一个网页（四个区域），保留服务器接口便于部署。已完成：

- 新增三个独立算法模块（各自 .h/.c，互不依赖界面）：
  - `maze.c/h`：二维数组迷宫 + 链表栈非递归 DFS + 三元组 (i,j,d) 输出；
    随机生成用“奇数坐标挖洞”，同 seed 结果可重现；自定义迷宫自动补墙。
  - `tree.c/h`：先序建树、递归/非递归三种遍历 + 层序、树形打印（├─ └─）、
    树(括号表示)⇄二叉树（左孩子右兄弟）、哈夫曼（静态数组树，支持频度表或按电文统计，`_` 表示空格）。
  - `graph.c/h`：云大呈贡校区 12 地点 21 条边的无向带权图；DFS/BFS、
    Dijkstra（prev 回溯路线）、Floyd 矩阵、哈密尔顿回路（回溯 + 步数上限 200 万）。
    中文表格对齐用 DisplayWidth/PadTo（汉字按 2 列）。
- `selftest.c`：30 条用例覆盖三个新实验（含无通路迷宫、Bellman-Ford 参考值校验
  Dijkstra、哈夫曼编码译码往返、回路访问点数），`make test-all`。
- `webui.c` 扩展：op 分发改为精确匹配（mazegen/mazesolve/tree/treeconv/huff/graph）；
  端口支持 `PORT`/argv，`HOST=0.0.0.0` 对外监听，`--no-open` 不弹浏览器。
  哈夫曼编码结果用 `===BITS===` 分隔符把 0/1 串带回给页面填充。
- `web/index.html` 重写为四区域布局（2×2 卡片，窄屏单列），实验一下有
  多项式/方程组子页，实验五下有二叉树/哈夫曼子页；校园导游的下拉框由
  `op=graph&mode=names` 动态填充。
- 验证：全部编译零警告；selftest 30/30；实验一 17/17；ASan/UBSan 下全接口
  压测无报错；`leaks` 检查 0 泄漏；无头 Chrome 截图确认四区域渲染正常。
- 经验：macOS 上 ASan 的 detect_leaks 不可用（用 `leaks <pid>` 代替）；
  headless 截图在新版 Chrome 需要 `--headless --no-sandbox`（`--headless=new` 会 GPU 崩溃）。
